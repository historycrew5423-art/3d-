# 08 · 练习游戏草稿（待定，还没开始做）

> 这是为了"演练一遍比赛流程"准备的练习点子，**不是比赛作品**，也还没定稿。
> 用途：第一次做游戏，模拟比赛的完整流程（设计 → 方块原型 → 试玩 → 生成模型 → 换模型打磨 → 发布）。
> 练习作品不会用于比赛（受"首个 commit 时间"和"不能换皮"两条规则约束）。

## 候选设定：漂流瓶小船
- **核心动作：** 开小船。
- **主角：** 一艘小木船（不需要骨骼动画，最省事）。
- **目标：** 60 秒内收集尽量多的漂流瓶。
- **挑战：** 撞到礁石扣 5 秒。
- **反馈：** 收集有音效+分数跳动；撞礁石屏幕红闪、船被弹开；时间到结算分数、可重开。
- **风格：** 低多边形卡通风，海面带波浪。
- **平台：** 手机和电脑都能玩，手机用虚拟摇杆。

## 演练中要专门测的三件事
1. 我怎么在**手机**上玩到游戏（GitHub Pages 网址 + 扫码）。
2. **Tripo 模型**生成后，文件怎么交给 AI 换进游戏。
3. 怎么把游戏**部署成一个公开网址**，以及代码更新后网址怎么自动更新。
