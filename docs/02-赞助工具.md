# 02 · 赞助工具清单与分工

> 都要先登录官网活动页「领取 token」，确认审核通过后再按各卡片步骤兑换。份数、期限各不相同，先选好要用的再领。

## 怎么分工（单人、不写代码、走网页游戏路线）

| 工具 | 干什么用 | 怎么领 / 注意 |
|---|---|---|
| **Tripo** | 生成 3D 模型：道具、场景、非人形角色 | 每人可申请 Pro + 3000 积分。先在 https://www.tripo3d.ai 注册，再从权益卡片入「Tripo x VibeFriends 选手服务群」，群里填表等审核发放。Studio 与 API 积分分开算。赛后清零 |
| **V2Fun** | 需要骨骼和动作的角色：自动绑骨、文字找动作、从视频提取动作（输出 BVH，可进 Blender/UE5/Unity） | 每人 1 个月 Pro；每队另可申请 5000 API 积分。Pro 兑换码在群里同步，去 https://v2fun.art 兑换；API 积分由每队一人提供队名和账号 ID 统一发放 |
| **FUMO（小宿科技）** | Fusion Max 2.0，可当备用 coding 模型（兼容 OpenAI API），或游戏里的 AI 对话 | 每人 $50 礼品卡，用于 Fusion Model。权益页复制专属链接→浏览器打开→Claim→登录后 Continue。**有效期仅 10-30 至 10-31**。产品入口 https://fumolab.ai |
| **硅基流动 SiliconFlow** | 游戏运行时调用大模型（如 NPC 对话） | 权益页领兑换码，登录 https://cloud.siliconflow.cn，余额充值→代金券→获取代金券→使用兑换码。兑换截止 2026-12-31 |
| **AI Ping** | 大模型 API 聚合/选型平台，调用各家模型 | 新用户先在 https://www.aiping.cn 注册，再从权益卡片领 68 元算力问卷，填注册手机号。每手机号限一次 |
| **Unity Codely（团结引擎）** | 只在走 Unity 路线时用 | https://codely.tuanjie.cn/topup 输兑换码。兑换窗口 10-30 00:00 至 11-01 00:00，兑换后积分 3 天内有效 |
| **Paean** | 可玩、可 Remix 小作品的社区，多一个曝光/灵感渠道 | 80 份权益，每份 5000 credits。权益页领码，去 https://one.paean.ai/account/gift 兑换 |

## 结论：我这次大概率用到的
- **Tripo**：生成模型（核心）。今天就申请，因为要入群填表等审核。
- **（可选）V2Fun**：如果主角是人形、要动作。但人形绑骨动作最费时间，能不用尽量不用。
- **（可选）硅基流动 / AI Ping**：只有游戏里要实时调 LLM（比如会说话的 NPC）才需要。注意 **API key 不能放前端**，要加一个简单的服务端代理。
- **FUMO**：备用 coding 模型，看情况。
- **Unity Codely**：Unity 路线的额度，**保留作为选项**。Unity 现在有官方 Claude Code/Codex 插件，AI 能扛掉不少，不因为"不熟"就排除——看启动会后定的点子要不要上 Unity（见 `04-技术路线.md` 路线 B）。
