# 02 · 赞助工具：完整清单、用途和领取顺序

> 来源：官网权益页 https://vibecafe.ai/hacks/6?tab=tokens （2026-10-29 用户从页面复制的完整内容）。比指南里的列表多了 Hyper3D、商汤小浣熊、VibeToken、MiniMax、智谱 GLM、three.js 六项。

## 一、按用途分组（对单人、不写代码的我有什么用）

### 1. 生成 3D 模型（最重要）
| 工具 | 内容 | 对我的用处 |
|---|---|---|
| **Tripo** | 每人 Pro 会员 + 3000 积分，Studio 或 API | 主力 3D 模型生成。**申请时 Studio 和 API 都填**：有 API 积分，AI 就能在沙盒里直接调 API 生成模型，我不用手动在网页里一步步操作 |
| **Hyper3D Rodin** | 4 天 Business 会员，支持 API 和 MCP | 第二个 3D 模型生成器，可以和 Tripo 对比挑效果好的。官方提供 API（curl 就能调）和 MCP（Claude Code、Codex、Kimi Code 可接入，浏览器授权，不用 API key） |
| **V2Fun** | 每人 1 个月 Pro；每队 5000 API 积分 | 人形角色专用：自动绑骨、用文字找动作、从视频提取动作。主角是人形才需要 |

今天这个会话里多次出现"模型无法继续对话"的报错，所以比赛当天最好**准备一个备用编程工具**。
| 工具 | 内容 | 备注 |
|---|---|---|
| **MiniMax** | 1 万积分，可用所有 M 系列模型 | 有 MiniMax Code（网页版和桌面版），对不写代码的人最容易上手。领取截止 11/2，到账后 30 天有效 |
| **智谱 GLM Coding Plan** | 7 天体验卡，2000 体验积分 | 只能在官方支持的编程工具里用（要配置专用 API Key），不能用于普通 API 调用。仅限从未订阅过的人 |
| **FUMO Fusion Max 2.0** | $50 礼品卡（官方称约等于 $300 的 Astra 用量） | 兼容 OpenAI 接口，需要一个支持自定义接口的编程工具。**只在 10/30 到 10/31 有效** |
| **Unity Codely** | 团结引擎的积分 | 只在走 Unity 路线时用。不需要填任何信息，兑换零成本，10/30 先兑上，保留选项 |
| **商汤小浣熊** | 3500 积分，桌面端 | 具体能力没查到可靠资料。优先级低，可以用来写路演稿、小红书文案 |

## 三、我的建议组合
- **写代码：** Kiro（Opus 5.5）主力，备用 MiniMax Code。
- **3D 模型：** Tripo 为主，Hyper3D 对比和补充。两家都有 API，可以让 AI 直接生成，我只负责挑。
- **人形角色动作：** V2Fun（主角是人形时才用）。
- **参考图和宣传素材：** VibeToken 的图像和视频模型。
- **引擎：** three.js；想试 Unity 就用 Codely。

## 四、让 AI 直接调用模型生成 API 要注意
- 要把 API key 发给 AI。key 等于账号密码，会留在聊天记录里。
- **key 绝不能提交进 GitHub 仓库。**
- 比赛结束后到对应平台把 key 删掉或重新生成。
- Hyper3D 的 MCP 方式不需要 key，但要在浏览器里授权；在 Kiro Web 里能不能用还没测试过。
